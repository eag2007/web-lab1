# Лабораторная работа №1

## Описание проекта

Веб-приложение для проверки попадания точки в заданную область на координатной плоскости.

Пользователь задаёт координаты точки `X`, `Y` и значение радиуса `R`, после чего приложение проверяет принадлежность точки заданной области. Область отрисовывается средствами `Canvas`.

Результаты проверок отображаются в таблице и сохраняются в `LocalStorage`, благодаря чему данные остаются доступными после перезагрузки страницы.

Также реализовано взаимодействие с координатной плоскостью: масштабирование, перемещение и создание точки двойным кликом по `Canvas`.

Интерфейс адаптируется под уменьшение ширины экрана: блок проверки точки переносится под график, а элементы управления перестраиваются в вертикальное расположение.

## Технологии

- **HTML5** — структура веб-страницы
- **CSS3** — оформление и адаптивная верстка
- **JavaScript ES Modules** — логика приложения
- **Canvas API** — построение координатной плоскости и заданной области
- **LocalStorage** — сохранение результатов между перезагрузками страницы
- **Decimal.js** — работа с вводимыми числовыми значениями
- **CSS Media Queries** — адаптация интерфейса под различные размеры экрана
- **DOM API** — взаимодействие JavaScript с элементами страницы

## Функциональность

### Проверка точки

Пользователь задаёт:

| Параметр | Допустимые значения |
|----------|---------------------|
| `X` | от `-5` до `3`, выбор из списка |
| `Y` | от `-3` до `3` |
| `R` | от `2` до `5` |

После нажатия кнопки **«Проверить»** выполняется валидация введённых данных и определяется попадание точки в заданную область.

При некорректном вводе пользователю отображается сообщение об ошибке.

### Координатная плоскость

Область строится средствами `Canvas` и состоит из нескольких геометрических фигур:

- четверти окружности;
- прямоугольника;
- треугольника.

Поддерживается:

- масштабирование графика колесом мыши;
- перемещение координатной плоскости мышью;
- создание точки двойным кликом по графику;
- автоматическое отображение добавленных точек.

### Таблица результатов

Для каждой проверенной точки отображаются:

| Поле | Описание |
|------|----------|
| `X` | Координата точки по оси X |
| `Y` | Координата точки по оси Y |
| `R` | Значение радиуса |
| Состояние | Попала точка в область или нет |
| Время проверки | Дата и время выполнения проверки |

Дата и время отображаются в русской локализации с учётом часового пояса клиентского устройства.

### LocalStorage

Все проверенные точки сохраняются в браузере с помощью `LocalStorage`.

После перезагрузки страницы:

- точки восстанавливаются;
- результаты снова отображаются в таблице;
- данные остаются доступными до очистки пользователем.

Кнопка **«Очистить»** удаляет сохранённые результаты и очищает таблицу.

## Адаптивность

Для небольших экранов используются CSS Media Queries.

При уменьшении ширины страницы:

- блок проверки точки перемещается под график;
- график занимает доступную ширину;
- поля ввода располагаются вертикально;
- кнопки располагаются друг под другом;
- шапка сайта адаптируется под ширину устройства.

## Установка и запуск

### Требования

Для локального запуска необходим современный браузер с поддержкой:

- JavaScript ES Modules;
- Canvas API;
- LocalStorage.

Из-за использования ES Modules рекомендуется запускать проект через локальный веб-сервер.

## Развёртывание на Helios

Проект размещается в директории `public_html` на сервере Helios.

Передача файлов:

```bash
scp -P 2222 -r index.html src public s502010@se.ifmo.ru:~/public_html/
```

После загрузки структура проекта и относительные пути к CSS, JavaScript и изображениям должны сохраняться.
